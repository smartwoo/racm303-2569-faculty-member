# RACM 303 (AY 2569) — Uploaded Instructor Slides & Teaching Files

โฟลเดอร์นี้สำหรับเก็บไฟล์สไลด์และเอกสารประกอบการสอนประจำคาบเรียน (`.pptx`, `.pdf`, `.docx`, `.key`) ที่อัปโหลดผ่าน **มุม Upload สื่อการสอน** บนเว็บพอร์ทัล หรืออัปโหลดโดยตรงผ่านหน้า GitHub Web Upload

- ตัวอย่างการตั้งชื่อไฟล์มาตรฐาน: `ST1_Slide.pptx`, `ST1_Slide.pdf`, `HS1_Slide.pptx`, `EP1_Slide.pdf`
- รายการไฟล์ที่ซิงค์อัตโนมัติจะถูกบันทึกใน `assets/data_slides_manifest.js` เพื่อให้ทั้งพอร์ทัลอาจารย์และนักศึกษาแสดงสถานะเปิดใช้งานทันทีบนทุกอุปกรณ์
